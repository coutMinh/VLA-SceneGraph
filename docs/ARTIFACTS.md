# Where the evidence lives

The repository holds code, protocols, small machine-readable results and README media.
Videos, numerical traces, environments and checkpoints stay outside it.

## In the repository

| Path | Content |
|---|---|
| `results/spatial/` | Spatial rerun (2026-10-30): `e0_summary.json`, `report.json` (S1/S2/T1 + controls), `latency_summary.json`, findings in `README.md` |
| `results/cross_suite/` | Object/Goal/Long follow-up: `manifest.json`, per-episode `metrics.json` + `intervention.json`, `summary.{md,json}`, findings in `README.md` |
| `results/registry.csv` | Every recorded run (smoke, parity, E0, S1/S2/T1, cross-suite). Original Molab paths are kept unchanged. Cross-suite rows use the original `xsuite-` prefix |
| `media/` | README chart and GIFs, generated by `scripts/plot_results.py` and `scripts/make_gif.py` |
| `tests/fixtures/scene_report.json` | Frozen Spatial scene-verification report used by the CPU tests |

Git line-ending conversion is disabled under `results/` so recorded hashes stay valid.
