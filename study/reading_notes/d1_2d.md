# D1 reading notes: compare by axis

Sources and verification scopes are in [the matrix](../literature_matrix.md).
These are agent-prepared notes for the student's reading; they do not assert
that the student has completed the planned reading hours.

**Representation and construction.** Johnson supplies a graph query and searches
for its image grounding; Xu predicts graph labels using iterative node/edge
messages. Thus graph representation and graph construction are separate choices.
[Johnson, sections 3/5](https://openaccess.thecvf.com/content_cvpr_2015/papers/Johnson_Image_Retrieval_Using_2015_CVPR_paper.pdf),
[Xu, section 3](https://arxiv.org/html/1701.02426).

**Assumptions and bias.** Xu uses contextual inference, while MotifNet stages
predictions through global sequential context. MotifNet's frequency baseline
questions whether a correct predicate reflects visual grounding or category
co-occurrence. **Our inference:** test identical object categories to separate
these explanations; this does not establish that pi0 has the same failure.
[Xu](https://arxiv.org/html/1701.02426), [Zellers, sections 3–5](https://arxiv.org/html/1711.06640).

**Time and evaluation.** Static-image graph recall in Xu/MotifNet differs from
Action Genome's human-object relation changes and action-recognition evaluation.
**Our inference:** neither evaluation establishes downstream robot success or
persistent identity through a grasp. Those require simulator evidence.
[Zellers](https://arxiv.org/html/1711.06640), [Ji, sections 3–5](https://arxiv.org/html/1912.06992).

Reading questions for D2: what geometry disambiguates identical objects; what
survives occlusion; which relations a controller needs; how robot-caused changes
update the graph; and whether graph improvements change task success. These
are our questions, not a claim that the literature has left them unanswered.
